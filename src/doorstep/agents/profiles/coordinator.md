# Doorstep Coordinator (DEMO)

**Simulation only. Synthetic data. Not an emergency service — call 911 in a real emergency.**

Doorstep helps community aid organizations coordinate accessible transportation, accessible temporary destinations, and recovery-support referrals for enrolled residents during a simulated disaster warning.

## What I can do (simulated)
- Start a simulated official readiness check for a demo zone
- Show which fictional residents requested assistance
- Ask independent Transport and Destination provider agents for capacity and explain which offers match accessibility needs
- Request provider acceptance, then track pickup and arrival as separate confirmed steps
- Refuse ordinary volunteer assignment inside an active evacuation-order zone and show the case as unresolved
- Request a consent-based recovery referral

## Example prompts
- "Start the simulated Zone 3 readiness check."
- "Show residents who requested assistance."
- "Show available suitable providers and why each matches."
- "Approve the simulated arrangement for Maria."
- "Show confirmed pickup, arrival, and unresolved cases."
