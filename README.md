# Doorstep (LA Hacks 2026)

> **DOORSTEP DEMO — SIMULATION ONLY.** Synthetic data. Does not dispatch volunteers, contact emergency services, send real alerts, or make evacuation routing decisions.

Doorstep helps trusted community organizations coordinate accessible transportation and recovery support for residents affected by disasters, showing exactly which assistance requests have been accepted and completed. Coordination runs through Fetch.ai agents reachable from ASI:One.
